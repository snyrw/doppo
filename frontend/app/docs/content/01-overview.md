title: Overview
---

Doppo is a sandbox to run basic mechanistic interpretability techniques on a wide range of TransformerLens models. We try to streamline workflows and provide QoL improvements over manually writing/running code. This is done by maintaining certain notebook standards while making the best of the flexibility and speed our format provides.

For now, these docs cover some of the basics ranging from techniques, model coverage, pricing, how and what we cache, intentional limits, and how to contact us. A lot of this is simple plaintext for now, and it should be mentioned that many parts of this project are subject to change.
